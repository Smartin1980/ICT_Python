# Dein erstes Python-Programm

Erstelle eine Datei mit dem Namen `hallo.py` und fuege diesen Code ein:

```python
name = "Python"
print(f"Hallo, {name}!")
```

Starte das Programm im Terminal:

```powershell
python hallo.py
```

Die Ausgabe sollte so aussehen:

```text
Hallo, Python!
```

## Was passiert hier?

`name` speichert einen Text. `print()` gibt diesen Text auf dem Bildschirm aus.
