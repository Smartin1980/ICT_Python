# 6. Codeknacker – Schleifen

## Ziel

Du lernst Wiederholungen kennen.

### `for`

Wenn du ungefähr weisst, wie oft etwas wiederholt werden soll:

```python
for versuch in range(3):
    print("Versuch", versuch + 1)
```

### `while`

Wenn etwas so lange wiederholt werden soll, bis eine Bedingung nicht mehr gilt:

```python
while tipp != geheimzahl:
    tipp = int(input("Dein Tipp: "))
```

Gib dem Spieler drei Versuche, einen Code zu knacken.
