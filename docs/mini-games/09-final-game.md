# 9. Python Quest – Final Game

## Ziel

Jetzt kombinierst du die wichtigsten Grundlagen:

- Variablen
- Datentypen
- Eingaben
- Operatoren
- Verzweigungen
- Schleifen
- Funktionen
- Zufall

## Idee

Erstelle ein kleines Text-Adventure.

Beispiel:

```text
Du stehst vor einer Höhle.

1 - Höhle betreten
2 - Weglaufen
```

Danach kann ein Monster erscheinen, der Spieler kann angreifen oder fliehen und Gold sammeln.

## Datei

`beispiele/mini-games/09_python_quest.py`

## Erweiterungen

Du kannst dein Spiel weiter ausbauen:

- mehrere Gegner
- Heiltränke
- Inventar
- verschiedene Räume
- Highscore
- mehrere Enden

Geschafft – du hast die wichtigsten Python-Grundlagen in kleinen Spielen eingesetzt.
