# 8. Monsterkampf – Funktionen

## Ziel

Du lernst, eigenen Code in Funktionen zu verpacken.

```python
def angreifen(schaden):
    return schaden
```

Eine Funktion kannst du danach immer wieder verwenden.

## Mini-Game

Baue einen einfachen Monsterkampf.

## Aufgabe

Erweitere das Spiel um eine zweite Funktion, zum Beispiel:

- `heilen()`
- `verteidigen()`
- `magie()`
