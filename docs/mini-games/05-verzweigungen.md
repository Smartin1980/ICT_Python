# 5. Zahlenraten – Verzweigungen

## Ziel

Du lernst, wie ein Programm Entscheidungen trifft.

```python
if tipp == geheimzahl:
    print("Richtig!")
elif tipp < geheimzahl:
    print("Zu klein!")
else:
    print("Zu gross!")
```

## Wichtige Vergleiche

- `==` gleich
- `!=` ungleich
- `<` kleiner
- `>` grösser
- `<=` kleiner oder gleich
- `>=` grösser oder gleich
