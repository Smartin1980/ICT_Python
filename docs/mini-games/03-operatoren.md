# 3. Gold & Shop – Operatoren

## Ziel

Du lernst mit Zahlen zu rechnen.

Wichtige Operatoren:

- `+` Addition
- `-` Subtraktion
- `*` Multiplikation
- `/` Division
- `//` Ganzzahldivision
- `%` Rest einer Division
- `**` Potenz

## Beispiel

```python
gold = 20
gold = gold + 10
```

Mit `%` kannst du zum Beispiel prüfen, ob eine Zahl gerade ist:

```python
if zahl % 2 == 0:
    print("Gerade")
```
