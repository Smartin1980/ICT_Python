# 1. Game Intro

## Ziel und Werkzeug

Du gestaltest einen Startbildschirm. Python führt Befehle von oben nach unten aus. `print("Hallo")` gibt Text aus; die Anführungszeichen erscheinen dabei nicht. `print()` ohne Inhalt erzeugt eine Leerzeile.

## Erst überlegen

- Wie baust du einen Rahmen aus Gleichheitszeichen?
- Was passiert, wenn du zwei `print()`-Zeilen vertauschst?

## Bauauftrag

1. Erstelle die Python-Datei und gib eine Linie aus Gleichheitszeichen aus.
2. Gib darunter den Titel `PYTHON ADVENTURE 2` und eine zweite Linie aus.
3. Füge eine Leerzeile ein.
4. Gib `Willkommen zu deinem ersten Python-Spiel!` aus.

## Tipps

Verwende für jede Ausgabezeile einen eigenen `print()`-Befehl. Auch die Rahmenzeichen sind Text und brauchen Anführungszeichen. Schliesse alle Klammern und Anführungszeichen.

## Teste dich

Starte die Datei. Erscheinen Rahmen, Titel, Leerzeile und Begrüssung in dieser Reihenfolge? Ändere den Titel, speichere und starte nochmals.

## Zusatzaufgabe

Gestalte einen eigenen Spieltitel und ein kleines Bild aus Textzeichen.

## Vollständiger Lösungscode

Vergleiche erst nach deinem eigenen Versuch. Dieser Code enthält das vollständige Grundspiel; die freiwilligen Zusatzaufgaben sind nicht eingebaut.
