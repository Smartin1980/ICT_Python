# Mini-Games mit Python

Baue Schritt für Schritt deine eigenen kleinen Spiele. Du brauchst Python und einen Editor wie VS Code.

## So lernst du mit diesen Seiten

1. Lies das Ziel und die Werkzeuge. Überlege bei den Denkfragen zuerst selbst.
2. Erstelle die angegebene Python-Datei und löse den Bauauftrag. Starte nach jedem kleinen Schritt.
3. Wenn du feststeckst, lies die Tipps und probiere nochmals.
4. Prüfe dein Spiel mit den vorgeschlagenen Tests.
5. Am Ende jeder Seite findest du den **vollständigen Lösungscode des Grundspiels**. Vergleiche ihn mit deinem eigenen Programm.

Du kannst den Code vollständig kopieren und starten. Versuche aber zuerst selbst eine Lösung zu bauen. Dein Code darf anders aussehen, solange er die Aufgabe erfüllt. Die **Zusatzaufgaben** sind freiwillig und noch nicht in der Lösung eingebaut.

## Programme starten

Lege für deine eigenen Lösungen den Unterordner `mini-games` in deinem Kursordner `python-kurs` an. Speichere dort deine Datei mit der Endung `.py`. Öffne in VS Code ein Terminal im Ordner deiner Datei und starte zum Beispiel:

```text
python 01_game_intro.py
```

Unter Windows kannst du auch `py 01_game_intro.py` verwenden. Unter macOS und Linux verwendest du `python3 01_game_intro.py`. Bei Fragen im Spiel klickst du ins Terminal, tippst deine Antwort und drückst Enter.
