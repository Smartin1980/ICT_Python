# Mini-Games mit Python

Baue Schritt für Schritt deine eigenen kleinen Spiele. Du brauchst Python und einen Editor wie VS Code.

## So lernst du mit diesen Seiten

1. Lies das Ziel und die Werkzeuge. Überlege bei den Denkfragen zuerst selbst.
2. Erstelle die angegebene Python-Datei und löse den Bauauftrag. Starte nach jedem kleinen Schritt.
3. Wenn du feststeckst, lies die Tipps und probiere nochmals.
4. Prüfe dein Spiel mit den vorgeschlagenen Tests.
5. Am Ende jeder Seite findest du den **vollständigen Lösungscode des Grundspiels**. Vergleiche ihn mit deinem eigenen Programm.

Du kannst den Code vollständig kopieren und starten. Versuche aber zuerst selbst eine Lösung zu bauen. Dein Code darf anders aussehen, solange er die Aufgabe erfüllt. Die **Zusatzaufgaben** sind freiwillig und noch nicht in der Lösung eingebaut.

## 🤖 KI als dein Python-Tutor

KI darf beim Lernen helfen. Sie soll aber als Tutor und nicht als Lösungsautomat eingesetzt werden.

Gute Nutzung:

- Code erklären lassen
- Fehlermeldungen verstehen
- einzelne Python-Befehle erklären lassen
- einen kleinen Hinweis verlangen
- Verständnisfragen beantworten
- sich selbst testen lassen

Nicht das Ziel:

- komplette Aufgaben lösen lassen
- fertigen Code blind kopieren
- Code verwenden, den man nicht erklären kann

Hebe diese Regel deutlich hervor:

**Du darfst KI benutzen – aber du musst deinen Code verstehen und erklären können.**

Füge danach folgenden Tutor-Prompt als kopierbaren `text`-Codeblock ein:

```text
Du bist mein persönlicher Python-Tutor.

Ich bin Anfänger:in und lerne gerade Python.

Hilf mir, meinen Code selbst zu verstehen und Probleme selbst zu lösen.

Regeln:
1. Erkläre einfach und verständlich.
2. Gib mir nicht sofort die fertige Lösung.
3. Stelle mir zuerst Fragen, damit ich selbst überlegen kann.
4. Wenn ich nicht weiterkomme, gib mir einen kleinen Hinweis.
5. Zeige erst dann Code, wenn ich trotz Hinweisen nicht weiterkomme.
6. Wenn ich dir Code gebe, erkläre ihn Schritt für Schritt.
7. Erkläre besonders Variablen, Datentypen, Operatoren, Bedingungen, Schleifen, Listen und Funktionen.
8. Bei Fehlern hilfst du mir, den Fehler selbst zu finden, statt ihn sofort zu verraten.
9. Stelle mir am Ende 1–2 kurze Verständnisfragen.
10. Ich soll meinen Code am Ende selbst erklären können.

Frage mich zuerst:

"Was glaubst du selbst, was dein Programm macht?"

Mein Code:

[MEIN CODE]
```

### CODE → KI → ICH

1. CODE – Probiere die Aufgabe zuerst selbst.
2. KI – Nutze die KI zum Erklären, Fragen oder für einen Hinweis.
3. ICH – Erkläre danach selbst, was dein Code macht.

## Programme starten

Lege für deine eigenen Lösungen den Unterordner `mini-games` in deinem Kursordner `python-kurs` an. Speichere dort deine Datei mit der Endung `.py`. Öffne in VS Code ein Terminal im Ordner deiner Datei und starte zum Beispiel:

```text
python 01_game_intro.py
```

Unter Windows kannst du auch `py 01_game_intro.py` verwenden. Unter macOS und Linux verwendest du `python3 01_game_intro.py`. Bei Fragen im Spiel klickst du ins Terminal, tippst deine Antwort und drückst Enter.
