# 4. Geheimcode – Eingaben

## Ziel

Du lernst, Eingaben vom Spieler abzufragen.

```python
name = input("Wie heisst du? ")
```

`input()` liefert immer Text zurück. Für Zahlen brauchst du zum Beispiel:

```python
alter = int(input("Wie alt bist du? "))
```

## Mini-Game

Frage Name, Alter und einen Geheimcode ab.
