# 7. Wörter raten – Listen

## Ziel

Du lernst, mehrere Werte in einer Liste zu speichern.

```python
woerter = ["python", "computer", "roboter"]
```

Auf einen Eintrag greifst du über seinen Index zu:

```python
print(woerter[0])
```

## Bonus

Mit `random.choice()` kannst du ein zufälliges Wort wählen:

```python
import random
geheimwort = random.choice(woerter)
```
