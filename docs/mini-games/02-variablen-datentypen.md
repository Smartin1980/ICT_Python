# 2. Character Creator – Variablen & Datentypen

## Ziel

Du lernst Variablen und die wichtigsten Datentypen kennen:

- `str` – Text
- `int` – ganze Zahlen
- `float` – Kommazahlen
- `bool` – `True` oder `False`

## Beispiel

```python
name = "Alex"
leben = 100
geschwindigkeit = 4.5
hat_schluessel = False
```
