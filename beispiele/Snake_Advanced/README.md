# Snake Advanced

Ein modernes Snake-Spiel mit `pygame`: Neon-Grafik, Partikel, Power-ups,
Portale, Hindernisse, Level-System, Pause-Menue und lokalem Highscore.

## Starten

```powershell
cd Snake_Advanced
python -m pip install -r requirements.txt
python main.py
```

## Steuerung

- Pfeiltasten oder WASD: Schlange steuern
- Leertaste oder P: Pause
- R: Neustart
- M: Ton ein/aus
- Esc: Zurueck zum Menue oder beenden

## Features

- Schoene Neon-Optik mit animiertem Hintergrund
- Mehrere Spielmodi: Classic, Maze und Portal Rush
- Power-ups: Slowdown, Shield und Score Boost
- Hindernisse, die mit dem Level anspruchsvoller werden
- Portale zum Teleportieren
- Partikel-Effekte fuer Futter, Power-ups und Kollisionen
- Highscore wird lokal in `highscore.json` gespeichert
